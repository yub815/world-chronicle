# 세계 정세 연대기

1936–1991년 세계 판도가 월 단위로 바뀌는 지구본과, 사건·국가·인물이 원인과 결과로 이어지는 연대기.

## 파일 구조
- `index.html` — 페이지 뼈대
- `css/style.css` — 디자인(색, 글꼴, 배치)
- `js/app.js` — 지구본·타임라인·뿌리 동작
- `data/events-*.js` — 사건 (id, 날짜, 제목, 요약 `s`, 쟁점 `q`, 원인 `k`, 관련 국가 `c`, 인물 `p`, 정당 `g`, 위치 `loc`)
- `data/people-*.js` — 인물
- `data/parties.js` — 정당·조직
- `data/countries.js` — 국가별 진영·이념·지도자 연표
- `data/territories.js` — 지역별 주인 변천(점령·식민지·독립)
- `data/wiki-photos.js` — 사건별 대표 사진을 가져올 영어 위키백과 문서 이름
- `data/borders.js` — 국경 도형 (직접 수정하지 마세요)
